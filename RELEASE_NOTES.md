**🎉 New Feature: Glass Radial Quick-Action Launcher & Focus Suite**
- **Layered Radial Dial:** Trigger custom action trees, open URLs, launch applications, or trigger system actions from a sleek floating glass interface.
- **Focus Pomodoro Timer & Eisenhower Matrix:** Integrated focus timer with custom presets that visualizes progress around the central bud, paired with a 4-quadrant task prioritization matrix.
- **Voice Dictation & Speech Synthesis:** Speech-to-text dictation and custom text-to-speech reading with local Whisper pipeline support and native voice selection.
- **Profile Starter Templates:** Instantly toggle between pre-configured setups (Maker, Coordinator, Explorer) or manage multiple saved configuration profiles.

**Features & Enhancements**
- **Custom Accent Colors:** Real-time appearance customization with smooth glassmorphism rendering and interactive bud sizing.
- **Global Hotkey Bindings:** Quickfire single actions and global shortcuts customizable directly from the settings panel.
- **In-App Update Previews:** Automatically fetch and preview markdown release notes and publication details directly inside Settings › About.
- **Cross-Platform System Controls:** Built-in support for controlling volume, dark theme, night light, DND, media keys, and terminal windows.

**Bug Fixes & Security**
- **Comment Stripping:** Updated release notes parsing to safely strip HTML comments and sanitize release bodies prior to rendering.
- **Config Recovery:** Automatic recovery and restore notifications for configuration files following unclean app shutdowns.
